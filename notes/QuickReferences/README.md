# Quick References

Short, standalone guides to tools and languages used across these courses.
Each guide lives in its own folder under a topic.

Path shape: `notes/QuickReferences/<Topic>/<Guide_Name>/`

## Guides

### Julia

- [Julia Programming Guide](Julia/Julia_Programming_Guide/) — Julia language
  reference (PDF, with a Markdown copy under `docx/`).

### Markdown

- [Pluto.jl Markdown Guide](Markdown/PlutoJL_Markdown_Guide/) — Markdown
  features that render inside Pluto.jl notebooks.

### LaTeX

- [LaTeX Math Guide](Latex/PLANNED-Latex_Math_Guide/) — planned; outline only
  so far.

### Python

- [Pytest: Tutorial and Reference](Python/Pytest_Guide/) — learn pytest from
  zero, then use it as a lookup reference. Markdown-native; the guide is the
  folder's `README.md`.

## Two folder shapes

- **Word-authored** (Julia, Pluto): a PDF at the folder root and a generated
  Markdown copy plus the `.docx` under a `docx/` subfolder.
- **Markdown-native** (Python/pytest): the guide is `README.md` at the folder
  root, with no `docx/` subfolder. See `STYLE_GUIDE.md` for the rules these
  follow.
