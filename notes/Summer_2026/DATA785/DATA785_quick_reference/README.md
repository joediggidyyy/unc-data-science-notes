# DATA 785 Quick Reference Study Guide

Open `index.html` in a modern browser. The site is fully client-side and requires no server.

Features include an always-visible navigation banner, drop-down table of contents and search interface, highlighted search results, keyboard shortcuts, light/dark themes, print styles, and links to the original weekly Markdown notes.

The guide is organized by topic. Where the course Markdown is sparse or malformed, the original gap remains documented and the added material is explicitly labeled **external gap fill** with direct links to the source used.
