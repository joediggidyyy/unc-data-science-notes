# DATA 785 Quick Reference Study Guide

Open `index.html` in a modern browser.

The package preserves the established site topology:

- `index.html`
- `assets/styles.css`
- `assets/app.js`
- `README.md`

The study-guide content, topic order, fixed banner, drop-down navigation, dark/light theme, and print behavior remain in place. This revision strengthens only the search layer.

## Enhanced search

- Subsection-, definition-, equation-, table-row-, and callout-level indexing
- Ranked results with breadcrumbs, type labels, snippets, and direct anchors
- Result-type filters for definitions, equations, procedures, comparisons, failures, examples, and gap fills
- Topic-scoped search and **Search this topic** controls
- Query normalization for common acronyms, aliases, plural forms, spaces, and hyphens
- Quoted phrase, `OR`, exclusion, and prefix syntax
- Keyboard result navigation
- Related-concept suggestions and closest-term suggestions
- Search state stored in URL parameters for bookmarking and sharing

### Query examples

- `MCP structure`
- `"agentic tool"`
- `LSTM OR GRU`
- `attention -RNN`
- `definition:MCP`
- `equation:cross-entropy`
- `source:external`

Use `/`, `Ctrl+K`, or `Command+K` to focus search. Use the arrow keys to move through results. A normal selection closes the menu; `Shift+Enter` keeps it open.
