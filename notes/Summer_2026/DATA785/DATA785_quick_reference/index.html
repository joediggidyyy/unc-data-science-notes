Topic 01

Predictive foundations: regression, loss, and optimization

Week 01 source

The course begins with linear and logistic models because the same ingredients recur throughout deep learning: parameters, differentiable loss, gradient-based training, validation, and regularization.

Linear regression

Predict a real-valued scalar from a feature vector.

ŷ = wTx + b

Parameters: weight vector w and bias b. A batch can be written as Ŷ = Xw + b.

Squared-error loss

Measure prediction error over training examples.

L(w) = ½ Σk(y(k) − ŷ(k))²

The factor ½ simplifies the derivative. Training seeks parameters that reduce this loss.

Gradient-based parameter update

θ ← θ − η ∇θL
  • θ: all trainable parameters.
  • η: learning rate, a hyperparameter.
  • Mini-batch SGD: estimate the gradient from a subset of examples, then update repeatedly.

Logistic classification

P(y = 1 | x) = σ(wTx + b)

The sigmoid maps a real-valued score to a probability. Classification uses a threshold or compares class probabilities.

LBCE = −[y log ŷ + (1−y) log(1−ŷ)]

Binary cross-entropy appears again in the backpropagation example. Maximum-likelihood training and cross-entropy are two views of the same objective.

Generalization and regularization

PatternTraining behaviorValidation behaviorResponse
UnderfittingPoorPoorIncrease capacity, improve features, train better.
Good fitGoodGoodRetain and verify on held-out test data.
OverfittingVery goodPoorRegularize, add data, simplify, or stop earlier.
objective = data objective − λR(W)

L2: penalizes squared weights. L1: penalizes absolute weights and encourages sparsity. Choose λ using validation performance, not the training objective.

Topic 02

Feedforward networks, MLPs, and nonlinearities

Week 02 sourceWeek 03 sourceWeek 05 sourceWeek 08 sourceExternal gap fill

A stack of linear transformations is still linear. Multi-layer perceptrons gain expressive power by inserting nonlinear activation functions between affine layers.

z(l) = W(l)a(l−1) + b(l)    ;    a(l) = σ(l)(z(l))
ActivationCompact formCourse useMain caution
Sigmoidσ(z)=1/(1+e−z)Binary probabilities; Week 03 derivationSaturates; small gradients at extremes
tanhtanh(z)RNN hidden statesCan still produce vanishing gradients
ReLUmax(0,z)CNNs; gradient-stability discussionInactive units can remain at zero
Recognition rule: If there is no nonlinearity between layers, collapse the weight matrices into one equivalent linear map.

External gap fill: MLP structure and capacity

Network anatomy

  • Feedforward: information moves from input to output through a directed acyclic computation graph; no output is fed back as recurrent state.
  • Depth: number of composed layers.
  • Width: number of units in a hidden layer.
  • Hidden representation: each layer transforms the previous representation into features useful to later layers.

Task-specific output layer

  • Regression: linear output with squared-error loss.
  • Binary classification: sigmoid output with binary cross-entropy.
  • Multiclass classification: softmax output with cross-entropy.
  • The hidden layers can be shared while the final activation and loss change with the prediction task.
a(0) = x   ;   a(l) = g(l)(W(l)a(l−1) + b(l))   ;   ŷ = fout(W(L)a(L−1) + b(L))

Capacity caveat: universal-approximation results show that sufficiently large feedforward networks can approximate broad classes of functions under stated conditions. They do not guarantee that gradient descent will find the function efficiently, that the network will generalize, or that a shallow network is the most parameter-efficient choice.

Topic 03

Backpropagation and gradient flow

Week 03 sourceWeek 08 source

Backpropagation applies the chain rule from the loss backward through the computation graph, reusing intermediate derivatives to obtain gradients for every parameter.

Forward pass

z(l) = W(l)a(l−1) + b(l)
a(l) = σ(z(l))

Cache values needed by the reverse pass.

Backward pass

δ(l) = ((W(l+1))Tδ(l+1)) ⊙ σ′(z(l))
∂L/∂W(l) = δ(l)(a(l−1))T

Procedure

  1. Compute the output-layer error derivative.
  2. Propagate the error backward from layer L−1 to layer 1.
  3. Form weight and bias gradients from each layer’s error and previous activation.
  4. Update parameters with the optimizer.

Gradient pathologies

Vanishing: repeated multiplication by small derivatives or weights drives gradients toward zero; early layers learn slowly.
Exploding: repeated multiplication by large factors makes gradients unstable; loss and parameters can diverge.

Course remedies: ReLU-style activations, batch/layer normalization, residual connections, and gradient clipping. Automatic differentiation systems implement the same reverse-mode chain rule over a recorded computation graph.

Topic 04

Text representation and word embeddings

Week 04 source

Representation learning replaces sparse, surface-level text counts with dense vectors whose geometry captures useful semantic or syntactic relationships.

Euclidean distance

d(a,b)=√Σi(ai−bi)²

Measures straight-line distance and is affected by vector magnitude.

Cosine similarity

sim(a,b)=(a·b)/(‖a‖‖b‖)

Measures direction: +1 same direction, 0 orthogonal, −1 opposite.

MethodPrediction taskInputOutput
Skip-gramPredict neighboring wordsCenter wordContext words
CBOWPredict the center wordContext wordsCenter word

Negative sampling intuition

  • Build positive pairs from words that occur within a context window.
  • Build negative pairs by randomly pairing words unlikely to share the context.
  • Train a binary classifier instead of normalizing over the entire vocabulary for every pair.
Window-size effect: shorter windows emphasize syntactic similarity; longer windows emphasize topical relatedness.
Topic 05

Convolutional neural networks

Week 05 sourceWeek 06 source

CNNs exploit locality and translation invariance. A shared filter slides across an image, producing feature maps without the parameter explosion of a fully connected image model.

Image→Convolution→Activation→Pooling / downsampling→Deeper features→Prediction

Convolution

A sliding dot product between local image patches and learned filters. Weight sharing dramatically reduces parameters.

Pooling

Max or average over local regions. No learned parameters in the basic form; reduces spatial size and increases invariance.

Padding and stride

Padding controls edge preservation. Stride controls how far the filter moves and therefore the output resolution.

Output geometry

output side = floor((input side + 2P − F)/S) + 1

P = padding, F = filter size, S = stride. Apply the same structure independently to width and height.

Parameter count

filters × F × F × input channels   +   filters biases
ArchitectureCourse takeaway
LeNetEarly handwritten-digit CNN.
AlexNetLandmark deep-CNN success; ReLU, L2, dropout.
VGGDeep homogeneous stacks of 3×3 convolutions.
ResNetResidual/skip connections enable very deep networks.

Topic 06

Training deep networks: normalization and residual paths

Week 06 source

Batch normalization

μ̂B = (1/|B|)Σx    ;    σ̂²B = (1/|B|)Σ(x−μ̂B)² + ε
BN(x) = γ ⊙ (x−μ̂B)/σ̂B + β
  • Normalizes using batch statistics, then learns a rescale γ and shift β.
  • Can smooth the optimization landscape and permit larger learning rates.
  • Training uses batch statistics; inference uses accumulated estimates.
  • Very small batches give noisy estimates; very large batches reduce the regularizing noise.

Layer normalization

Normalizes each example independently across its feature dimensions. It does not depend on batch size, and the forward computation is the same at training and test time.

Residual connection

y = F(x) + x

The identity path guarantees that a deeper block can preserve a simpler mapping. Residuals improve gradient flow, reduce gradient shattering, and make repeated deep blocks practical. A 1×1 convolution can align dimensions when the shortcut and block output differ.

Memory hook: normalization stabilizes activations; residual connections stabilize information and gradient paths.
Topic 07

Sequence modeling: probability, n-grams, and RNNs

Week 07 source

Autoregressive factorization

P(x1,…,xn) = ∏i=1…nP(xi | x1,…,xi−1)

Each next item is conditioned on the preceding sequence. This is the probabilistic basis of language modeling.

ModelContextStrengthLimitation
BigramPrevious tokenSimple and cheapVery limited context
Trigram / n-gramPrevious n−1 tokensMore fluent local structureSparse counts; fixed context
RNNRecursive hidden stateVariable-length context and shared parametersSequential training; gradient problems

RNN recurrence

ht = σ(Whht−1 + Wxxt + b)
ŷt = λ(Woht)

The hidden state recursively combines the current input with prior state. For generation, sample the next token from the output distribution and feed it into the next step.

Markov trade-off: limiting history controls complexity but prevents true long-range dependence. RNN state is intended to compress longer history into a fixed-size vector.
Topic 08

RNN training and sequence decoding

Week 08 sourceExternal: LSTMExternal: GRU

Training

  • Teacher forcing: during training, feed the true previous token rather than the model’s sampled prediction.
  • Cross-entropy: at each step, penalize low probability assigned to the true next token.
  • Backpropagation through time: unroll the recurrence and differentiate through repeated uses of the same weight matrix.
  • Gradient clipping: cap large gradients to control explosion.
Lt = −log ŷt[wt+1]

External gap fill: gated recurrent units

GRUs and LSTMs create additive, gated paths through time so the model can retain, overwrite, or expose information instead of replacing the hidden state with one unconstrained nonlinear update.

LSTM

it = σ(Wiixt + bii + Whiht−1 + bhi)
ft = σ(Wifxt + bif + Whfht−1 + bhf)
gt = tanh(Wigxt + big + Whght−1 + bhg)
ot = σ(Wioxt + bio + Whoht−1 + bho)
ct = ft ⊙ ct−1 + it ⊙ gt
ht = ot ⊙ tanh(ct)

Gate roles: input writes candidate content; forget retains or removes prior cell state; output controls what the hidden state exposes.

GRU

rt = σ(Wirxt + bir + Whrht−1 + bhr)
zt = σ(Wizxt + biz + Whzht−1 + bhz)
nt = tanh(Winxt + bin + rt ⊙ (Whnht−1 + bhn))
ht = (1−zt) ⊙ nt + zt ⊙ ht−1

Gate roles: reset controls how prior state contributes to the candidate; update interpolates between the candidate and previous hidden state.

CellPersistent stateGatesQuick distinction
Simple RNNhtNoneReplaces state with one nonlinear recurrence.
GRUhtReset, update, candidateCombines memory and exposed state in one vector.
LSTMct and htInput, forget, candidate, outputSeparates long-term cell state from exposed hidden state.

Topic 09

Transformers, pretraining, and fine-tuning

Week 09 sourceWeek 11 sourceExternal gap fill

Transformers replace recurrent state propagation with attention over token representations. Training can process positions in parallel; causal masking preserves autoregressive generation.

External gap fill: scaled dot-product attention

Q = XWQ   ;   K = XWK   ;   V = XWV
Attention(Q,K,V) = softmax(QKT/√dk + M)V
  • Queries: what each position is looking for.
  • Keys: what each position offers for matching.
  • Values: the content combined after the query–key scores become attention weights.
  • Scaling: divide by √dk before softmax to keep large dot products from producing overly sharp distributions.
  • Mask M: use 0 for allowed pairs and −∞ for disallowed future positions in causal attention.
headi = Attention(QWiQ, KWiK, VWiV)
MultiHead(Q,K,V) = Concat(head1,…,headH)WO

Documented notes gap and external fill: Week 09 discusses Q/K/V dimensions and causal masking but does not render the standard attention equation as text. The equation and multi-head expansion above were filled from Vaswani et al., “Attention Is All You Need”.

Core dimensions

  • L: layers
  • H: attention heads
  • dqk: query/key dimension
  • dv: value dimension
  • dmodel = H·dv
  • dff ≈ 4dmodel

Causal masking

Set attention scores for future positions to −∞ before softmax. A token can attend only to itself and earlier tokens.

ArchitectureTraining / behaviorTypical tasks
Encoder-only (BERT)Bidirectional self-attention; masked language modeling; notes also list next-sentence predictionClassification and token labeling
Decoder-only (GPT)Causal next-token predictionGeneration and completion
Encoder-decoder (T5, BART)Encode source, autoregressively decode targetTranslation, summarization, text-to-text tasks

Fine-tuning checklist

  1. Choose sequence-level or token-level output.
  2. Replace pretraining heads with a task-specific output layer.
  3. Train on labeled downstream data while updating the pretrained weights.
  4. Use a smaller learning rate than pretraining to reduce catastrophic forgetting.
  5. Evaluate both task quality and retained general capability.
Why transformers train well: parallelized sequence processing, layer normalization, residual connections, and short gradient paths compared with recurrent unrolling.
Topic 10

Generative modeling: normalizing flows and diffusion

Week 10 sourceExternal gap fill

Generative models learn a data distribution so they can create novel samples and, in some families, evaluate sample likelihood. The notes contrast exact-likelihood normalizing flows with iterative denoising diffusion models.

Normalizing flows

  • Transform a simple latent variable z through invertible layers into data x.
  • Each layer needs an efficient inverse and tractable Jacobian determinant.
  • Common pieces: invertible element-wise transforms, permutations, and coupling layers.
  • Pros: maximum-likelihood training; sampling and likelihood evaluation.
  • Constraint: architecture must preserve invertibility and tractable determinants.

Diffusion models

  • Forward process gradually adds Gaussian noise.
  • A neural network learns to reverse the process.
  • Training samples a time step and noise, creates a noisy input, predicts the noise, and minimizes MSE.
  • Generation begins with noise and iteratively denoises.
  • The notes connect the objective to an evidence lower bound (ELBO).

Diffusion training loop

sample x₀→sample t and ε→construct xt→predict ε̂θ(xt,t)→MSE(ε̂,ε)

External gap fill: corrected forward diffusion

q(xt | xt−1) = 𝒩(xt; √(1−βt)xt−1, βtI)
αt = 1−βt   ;   ᾱt = ∏s=1…tαs
q(xt | x0) = 𝒩(xt; √ᾱtx0, (1−ᾱt)I)
xt = √ᾱtx0 + √(1−ᾱt)ε   ,   ε ∼ 𝒩(0,I)

The stepwise process is a fixed Markov chain: βt controls the variance added at step t. The closed form allows training to sample any time step directly from x0 without simulating every earlier noising step.

Lsimple = 𝔼t,x₀,ε[‖ε − εθ(xt,t)‖²]

The commonly used simplified objective trains the network to predict the Gaussian noise that produced xt. Sampling uses the learned reverse transitions to move from xT toward x0.

Compact normalizing-flow identity
z ∼ pZ → f1 → … → fn → x ∼ pX

The data density is obtained by transforming the base density and accounting for volume change through the Jacobian determinant.

What each intervention changes

MethodTimeWeights?Primary purpose
PretrainingTrainingYesBroad next-token capability

RLHF / preference optimizationPost-trainingYesOptimize behavior preferred by raters

Prompt engineering checklist

  • Define measurable success before rewriting the prompt.
  • State task, context, constraints, priorities, and completion criteria.
  • Use consistent examples and explicit output structure.
  • Separate trusted instructions from untrusted source text.
  • Require abstention when evidence is insufficient.
  • Test normal cases, edge cases, and adversarial cases.

RLHF pipeline

  1. Begin with a pretrained, commonly SFT model.
  2. Collect human comparisons among candidate responses.
  3. Train a reward model to predict preference.
  4. Optimize the policy, classically with PPO.
  5. Use a KL penalty to limit drift from the reference model.
Alignment ≠ factuality. A reward model predicts rater preference; it is not a truth oracle. Polished behavior can make unsupported claims more convincing.

Emergent abilities

In the assigned paper, an ability is emergent when smaller models remain near chance and larger models rise substantially above chance. Thresholds are experiment-specific and can shift with metrics, data, architecture, and training procedure.

RAG architecture

Query→Dense retriever→MIPS top-k passages→Generator + evidence→Answer + provenance
MemoryLocationAdvantageFailure mode
ParametricModel weightsFast pattern completionHard to update, inspect, or attribute
Non-parametricExternal indexEditable, searchable, sourceableRetrieval miss, poisoning, chunking, latency

RAG-Sequence: one latent document distribution supports the sequence. RAG-Token: document support can vary by generated token.

Topic 12

Agents, tool use, workflow patterns, and MCP

Week 12 source

An agentic system combines a model with an environment, tools, state, a control loop, evaluation, and explicit authority boundaries. Autonomy is justified only when fixed workflows cannot predict the necessary steps.

Task / goal→Plan→Action→Observation→Evaluate / reflect↺Finish or replan

Workflow versus agent

DimensionWorkflowAgent
Control pathPredefined in codeDynamically selected by model
Best fitStable, specified processOpen-ended task with unpredictable steps
PredictabilityHigherLower
Main riskBrittle branchesCompounding errors, loops, unsafe actions

CoT versus ReAct

  • CoT: internal reasoning trajectory; no environmental feedback.
  • Act-only: tools and observations; weak explicit planning.
  • ReAct: interleaves thought, action, and observation—“reason to act” and “act to reason.”

Production patterns

PatternUse whenMain caution
Prompt chainingFixed sequence of clean subtasksEarly errors propagate
RoutingInputs belong to distinct categoriesWrong route poisons the result
ParallelizationIndependent work or votingCost and aggregation
Orchestrator-workersSubtasks cannot be predicted in advanceDelegation and synthesis failures
Evaluator-optimizerQuality criteria support iterative revisionLoops and over-optimization
Autonomous agentOpen-ended work with verifiable progressUnbounded cost and permission risk

Function-calling contract

  1. Declare a minimal, well-described tool inventory.
  2. The model proposes a structured call.
  3. Application code validates schema, permissions, and policy.
  4. The application executes the tool.
  5. The result returns as an observation.
  6. The system checks completion or replans.

MCP

Model Context Protocol standardizes how AI hosts connect to servers exposing context and capabilities. It does not provide correct planning, authorization, evaluation, or trust by itself.

Role / capabilityMeaning
HostAI application managing model, policies, UX, and connections
ClientHost-side connector for one MCP server
ServerService exposing resources, prompts, or tools
ResourcesReadable context
PromptsTemplated messages or workflows
ToolsCallable functions
ElicitationServer request for additional user input through the host
Agent-computer interface: tool names, descriptions, schemas, examples, errors, and completion conditions are part of the prompt. Design them as carefully as a human interface.
Topic 13

Evaluation, reliability, and security controls

Week 11 sourceWeek 12 source

System quality must be measured component by component. A good demonstration does not establish dependable task success, grounding, safety, or cost.

DimensionQuestionMeasures
Task successDid the system complete the job?Accuracy, exact match, rubric, human review
GroundednessAre claims supported?Citation precision/recall, entailment audit
RetrievalWas needed evidence found?Recall@k, MRR, nDCG, gold overlap
Instruction followingWere scope and format respected?Schema and constraint checks
CalibrationDoes confidence track correctness?Brier score, ECE, abstention quality
Safety / robustnessCan hostile input bypass controls?Red-team and policy-violation rate
EfficiencyIs deployment practical?Latency, tokens, tool calls, throughput, review load

Threats

Instruction attacks

Prompt injection and jailbreaks attempt to override trusted goals.

Data attacks

Training or retrieval poisoning introduces false evidence or backdoors.

Action risk

Tool misuse turns a model error into an external consequence.

Layered controls

  • Separate trusted instructions from untrusted data.
  • Use least-privilege tools, allowlists, argument validation, rate limits, and confirmation.
  • Retain provenance and verify evidence supports each claim.
  • Use deterministic validators around structured outputs and transactions.
  • Budget tokens, time, calls, retries, and money; detect loops.
  • Require human approval for high-impact or irreversible actions.
  • Log actions, observations, evidence, and decisions for audit.
P(all 10 independent steps succeed) = 0.9510 ≈ 59.9%

Even strong per-step reliability compounds poorly over long horizons. Reduce steps, validate intermediate state, checkpoint progress, and design bounded recovery.
